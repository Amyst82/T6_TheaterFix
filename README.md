# T6 TheaterFix
### Vibecoded fix for redacted's (t6mpv43) demo displaying issue when it couldn't display more than two demos and displayed demos were with same metadata.

# Installation 
Drop TheaterFix.Red32n to your ...\Redacted\Plugins\ folder.
